# Vision Transformer Time Frequency Attention - Audio Classification Project

Repositori ini berisi kode implementasi dan pelatihan model *Deep Learning* menggunakan PyTorch. Proyek ini dirancang agar mudah dijalankan ulang, baik secara lokal maupun melalui Google Colab.

## 📂 Struktur Proyek
- `notebooks/` : Berisi file Jupyter Notebook (`.ipynb`) utama untuk alur kerja dari *preprocessing* hingga evaluasi model.
- `requirements.txt` : Daftar *library* Python yang dibutuhkan untuk menjalankan proyek ini.

## 🚀 Cara Menjalankan
1. Download atau *clone* repositori ini.
2. Install seluruh kebutuhan *library* dengan menjalankan perintah berikut di terminal:
   ```bash
   pip install -r requirements.txt
